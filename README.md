# personal

Personal [Scoop](https://scoop.sh) bucket.

## Usage

```powershell
scoop bucket add personal https://github.com/idlercloud/scoop-bucket
scoop install personal/<app>

scoop update          # refresh the bucket
scoop update <app>    # upgrade an app
```
